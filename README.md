# Python File Processing Lab (AMCS1034 Chapter 4C)

A learning site for students: text files, file paths, os.path, access modes, reading, writing, closing, file exceptions, the with statement, os and shutil.

- **Learn**: full notes with a file-cursor demo and an access-mode demo
- **Code Lab**: 24 runnable examples (Python runs in the browser)
- **Quiz**: 27 multiple-choice questions with explanations
- **Exam Practice**: 10 structured questions with model answers

Live site: https://kasonkuek.github.io/AMCS1034-Chapter4c_File_Processing/
